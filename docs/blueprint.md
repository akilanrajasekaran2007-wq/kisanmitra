# **App Name**: KrishiMitraAI

## Core Features:

- Image Analysis via Gemini: Upload crop images for AI-powered diagnosis of pests, diseases, and nutrient deficiencies. The analysis uses the Gemini Vision API to provide a primary diagnosis, explain the reasoning, and suggest actionable steps. A tool that incorporates reasoning.
- Contextual Data Input: Collect crop name, location (GeoPoint), and farmer's notes to enhance Gemini's analysis and recommendations. Required contextual information is delivered along with the image.
- Holistic Recommendations: Integrate Gemini's analysis with soil data and weather forecasts to provide hyper-personalized advice on pest/disease control, irrigation, and fertilization.
- Weather Forecast: Display weather forecasts for the farm location using a weather API, with data cached for offline use.
- Offline Mode: Enable offline access to the app and its latest data using Firebase Firestore's offline persistence.
- Multi-Language Support: Offer the app in multiple Indian languages to ensure accessibility for all farmers.

## Style Guidelines:

- Primary color: Saturated green (#7CFC00) to represent plant health and growth.
- Background color: Light desaturated green (#F0FFF0).
- Accent color: Yellow-Green (#9ACD32) for highlighting important information and calls to action.
- Body and headline font: 'PT Sans' (sans-serif) for clear readability in both headings and body text.
- Use clean, simple icons to represent different features and data points, aiding in intuitive navigation.
- Design a clean, icon-driven interface, presenting AI-analyzed data in an actionable format on the dashboard.
